# solar-battery-tester-code

This is code to run on a Raspberry Pi with the solar-battery-tester that will.

[ ] Charge the battery (monitoring input current and voltage)
[ ] Check Over Current Discharge at 3A
[ ] Check Short Circuit Protection
[ ] Discharge the battery at 2.5A (monitoring output current and voltage)
[ ] Charge the battery to 12V and monitor voltage over 24 hours
